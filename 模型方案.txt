小型 Transformer 语言模型方案（当前正式版本：英文 TinyStories 单语）

目标与边界
- 从随机初始化训练可在 RTX 4060 Laptop GPU（8 GB 显存）上运行的小型 decoder-only 语言模型。
- 能解释 token → embedding → attention → MLP → logits → loss → backward → AdamW。
- 正式训练与任务 A、任务 B 均只使用英文 TinyStories；此前中英混合方案仅作历史复盘。
- 笔记本可用内存约 13 GB。模型规模保留了多层、多头和完整训练流程，同时能在本机完成训练。

模型架构
- Decoder-only causal Transformer；8 个 block；hidden size 512。
- 8 个 attention heads，每个 head 64 维；MLP 为 512 → 2048 → 512，激活函数 GELU。
- 最大上下文 512 token；RoPE 位置编码（base 10000）；Pre-LN LayerNorm；dropout 0.1。
- 输入 token embedding 和输出 lm_head 共享权重；实际参数量 33,412,096。
- 因果 mask 禁止读取未来 token。模型对每个输入位置输出 16,000 维的下一个 token logits。

正式数据与 tokenizer
- 唯一语料：roneneldan/TinyStories 英文故事；不使用中文 Wikipedia 或项目文档训练。
- 按文档划分训练/验证：训练 196,702 篇，验证 3,947 篇。
- 训练文本编码成 42,074,460 token；验证文本编码成 842,751 token。
- 使用英文训练文本单独训练 16,000 词 SentencePiece Unigram；特殊 token 为 <pad>、<bos>、<eos>、<unk>。
- 文件：data/english_single/processed/、tokenizer/english_single/。
- data/english_single/manifest.json 记录来源、文档数、token 数和文件 SHA-256。

基础训练
- PyTorch 2.5.1+cu124；CUDA；FP16 mixed precision 与 GradScaler。
- micro-batch 4 条 × 512 token，梯度累积 4 次，每次 optimizer 更新处理 8,192 个目标 token。
- AdamW：初始学习率 3e-4、最小学习率 3e-5、betas (0.9, 0.95)、weight decay 0.1。
- 先 warmup 500 步，再 cosine decay；梯度范数裁剪到 1.0。
- 随机窗口采样；固定验证窗口；日志和 checkpoint 定期落盘。
- 配置：configs/english_single/base.yaml；模型、optimizer、GradScaler、训练步数和 RNG 均在新目录初始化。
- 完成 29,297 步，共 240,001,024 seen tokens。最终模型：
  checkpoints/english_single/base/final_step_00029297.pt。
- 最后一次记录的英文验证 loss 为 1.5810，perplexity 为 4.8599（第 29,250 步）。
- 训练日志：experiments/english_single/base/tensorboard/train.jsonl 与同目录 TensorBoard event 文件。

任务 A：KV cache 推理优化
- 固定英文基础模型最终 checkpoint、同一提示词、相同解码参数，比较逐步重算与复用每层 K/V。
- 每次生成 128 token，batch 1，FP32；32 与 256 token 英文提示词各测 5 次。
- 两种长度的中位耗时加速均约 1.02 倍；贪心与固定 seed 随机输出一致。
- 增量 logits 最大绝对差约 4.77e-6；跨 512 token 上限重建缓存时输出仍一致。
- 原始逐次结果和方法：experiments/english_single/task_a/kv-cache-results.json、kv-cache-report.md。

任务 B：训练中上下文长度增长或截短
- 研究变量是训练窗口的可见历史长度，不是生成时只截断 prompt。
- 从独立的共同随机初始状态出发：parent128、parent512 各训练 9,766 步；
  在每条路径的 token 中点分叉成 128-128、128-512、512-512、512-128。
- 每阶段 80,003,072 目标 token，每条完整路径 160,006,144 目标 token。
- 四条子路径使用相同数据抽样链；相同父模型的两个子分支复制完整模型与 optimizer 状态。
- 固定 64 个英文验证窗口，只计算最后 128 个相同目标位置；
  L128/L256/L512 分别表示提供 128/256/512 token 历史时的平均负对数似然，
  G=L128-L512 表示长历史相对短历史的收益。
- 最终结果（L128, L512, G）：
  128-128: (1.7874, 3.6949, -1.9074)
  128-512: (1.7919, 1.6099,  0.1819)
  512-512: (1.7931, 1.5944,  0.1986)
  512-128: (1.7852, 1.6315,  0.1537)
- 设计与限制：notes/task-b-english-single-plan.md；
  完整结果：experiments/english_single/task_b/task-b-report.md。
