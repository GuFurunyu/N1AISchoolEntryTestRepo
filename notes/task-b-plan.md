# 历史记录：中文训练上下文增长或截短的双向实验（旧方案）

> 本文件属于已冻结的中英混合方案。英文单语正式实验使用
> `notes/task-b-english-single-plan.md` 和
> `experiments/english_single/task_b/task-b-report.md`；本文件保留用于历史复盘，
> 不作为新训练、验证或结论的输入。

## 问题

同一个随机初始化的小型 Transformer，在中文语料上先以 128 或 512 token 的窗口训练约 8000 万 token；随后保持窗口长度或切换到另一长度，再训练约 8000 万 token。训练上下文从短到长、从长到短时，中文预测能力和利用较长历史的收益如何随训练步骤变化？

模型最大支持 512 token。这里的“128”是把相同原始训练窗口切成独立的 128-token 片段，使 attention 在片段边界重新开始；它不是把 attention head 数改成 128。只在生成时截断提示词不足以研究 training dynamics，所以本实验实际更新四条路径的权重，并记录切换前后的指标轨迹。

## 事前假设

- H1：分叉时，512 父模型在 512-token 验证历史下，相对 128-token 历史会有更大的损失下降；128 父模型学到的远距离利用能力可能较少。
- H2：从 128 切到 512 后，长历史带来的额外收益应逐渐增加，速度快于 128→128 对照。
- H3：从 512 切到 128 后，长历史的额外收益可能逐渐缩小，或至少比 512→512 对照增长得慢。这里不预先称为“遗忘”：若长历史损失本身也下降，只是短历史下降更快，不能说绝对能力退化。

理由：较长训练窗口允许预测某个 token 时使用更远的中文信息，较短窗口会频繁重置这一信息。但中文 Wikipedia 的可预测信息可能主要在局部，模型也可能学不会有效利用更远历史，所以上述方向并不确定。

## 固定的四条路径

    同一个随机初始权重
    ├─ parent128：先训练 9766 步 ──┬─ 128-128：再训练 9766 步
    │                             └─ 128-512：再训练 9766 步
    └─ parent512：先训练 9766 步 ──┬─ 512-512：再训练 9766 步
                                  └─ 512-128：再训练 9766 步

每步恰好处理 8192 个目标 token，所以每阶段为 80,003,072 token，每条完整路径为 160,006,144 token。分叉点严格位于各路径的训练 token 中点。第一阶段只运行两个父模型；第二阶段从父检查点完整复制模型、AdamW、GradScaler、学习率步骤、数据 RNG 和 PyTorch CPU/CUDA RNG。相同父模型的两个子分支在分叉前的状态应完全相同。

## 控制方法

- 沿用现有 8 层、512 维、16k SentencePiece 模型结构和 tokenizer，但从同一随机权重开始，不加载之前训练好的 240M-token 模型。
- 所有阶段只使用同一 train.bin 的中文区域。每个优化步骤先抽取 16 个相同的 512-token 原始窗口，再按本阶段的 128 或 512 切分。两种长度预测的目标 token 完全相同，每步 token 总数、优化器更新次数、学习率日程和训练语料都相同；改变的是每个目标能看到的历史及 RoPE 位置重置。
- 数据抽样使用独立 NumPy RNG，不受 dropout 消耗的 PyTorch RNG 影响。分支之间记录滚动数据摘要；若相同阶段的摘要不一致，不能把结果当作受控对照。
- 对每个父模型，只比较其两个子分支的差异：128-512 对 128-128，以及 512-128 对 512-512。跨父模型的最终差异不能直接解释为切换方向的纯效应，因为其前半段权重不同。

## 预先确定的测量

固定验证文件中文区域的 64 个原始 512-token 窗口。对同一批窗口分别提供 128、256、512 token 历史，但只计算最后 128 个相同目标位置的平均交叉熵，记作 L128、L256、L512。主要观察 G = L128 - L512，它是使用较长历史时的损失收益；同时必须展示 L128 和 L512 本身，避免只看差值误判“遗忘”。该比较仍包含 RoPE 位置编号改变的影响，因此不等于纯粹的远距离语义信息量。

按固定步数记录训练 loss、三种验证 loss、吞吐、学习率和跳过更新次数。分叉后第 1、10、50、100、250、500 步以及此后每 500 步做验证，以便观察切换瞬间与长期趋势。中文自由生成使用相同验证文档提示词、随机种子、temperature 和 top-k，仅作为需要人工审阅的补充；少量样例不能单独证明质量优劣。

## 失败、冲突和仍未知的排查规则

若分叉时两个父模型没有可测的长历史收益差异，不能把第二阶段解释成“已有长历史能力的获得或失去”；报告将如实说明。若子分支数据摘要、初始权重或优化器状态不一致，先修复控制和测量，再重跑受影响的分支。若 G 与假设冲突，先查看原始 L128/L512 及每个验证窗口的成对差，再判断是指标设计、训练不稳定，还是假设本身错误。若生成文字与验证 loss 不一致，不用主观样例覆盖量化结果。

本实验为一个初始化种子、一个中文 Wikipedia 来源和固定训练预算；即使看到差异，也不能声称对所有语料和模型普遍成立。旧版中断的上下文试验已按用户要求清理，不用于此实验的结果。
